# TopuHud

A comprehensive utility HUD mod for Minecraft Fabric 1.20.x with customizable UI elements and performance monitoring.

## Features

- **Toggle Menu**: Press `R Shift` to open/close the HUD menu
- **HUD Customization**: Press `R Control` to enter HUD editing mode and move UI elements
- **Armor Status**: Display current armor durability
- **Clock**: Real-time in-game clock
- **Direction**: Current facing direction (N, S, E, W)
- **Coordinates**: Current player position (X, Y, Z)
- **Memory Usage**: Display RAM usage
- **FPS Counter**: Frame rate display
- **CPS Counter**: Clicks per second counter
- **Combo Counter**: Track hit combos
- **Particle Effects**: Customizable particle effects for crits
- **Module Display**: Show active modules and status
- **TopuClient Integration**: Display TopuClient player tags with "tc_" prefix

## Installation

1. Install Fabric Loader 0.19.3
2. Download the mod JAR file
3. Place it in your `.minecraft/mods` folder
4. Launch Minecraft with Fabric profile

## Usage

- **Open HUD Menu**: Press `R Shift`
- **Edit HUD Layout**: Press `R Control`
- **Toggle Features**: Use the menu to enable/disable individual features
- **Customize Particles**: Access particle settings in the cog menu
